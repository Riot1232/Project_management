## О проекте

Работа выполняется последовательно в течение семестра.

На первой фазе команда рассматривает несколько концепций программного проекта и с помощью коллективных экспертных методов выбирает одну из них для дальнейшей проработки.

После выбора дальнейшая работа выполняется уже для одной концепции: проект декомпозируется на работы и задачи, описываются сценарии использования, выполняется оценивание, прогнозирование и планирование.

По результатам первой фазы для дальнейшей работы выбрана концепция:

> **A2 — Система автоматизации внутренних заявок и сервисных запросов**

## Содержание репозитория

### Таск трекер

Материалы для организации командной работы:

- распределение задач между участниками;
- матрица RACI;
- контроль выполнения работ.

### Фаза 1 — Выбор концепции проекта

Выбор одной концепции программного проекта из нескольких альтернатив с использованием двух методов коллективной экспертной оценки:

- нечёткого коллективного TOPSIS;
- чёткого коллективного метода анализа иерархий (МАИ).

В папке размещены:

- рассматриваемые концепции;
- критерии оценки;
- экспертные оценки участников команды;
- расчётные таблицы;
- отчёты по TOPSIS и МАИ;
- итоговые результаты выбора концепции.

**Результат фазы:** выбрана концепция  
**A2 — Система автоматизации внутренних заявок и сервисных запросов**.

### Фаза 2 — Распределение работы

Материалы, связанные с декомпозицией выбранного проекта на работы и задачи и распределением ответственности внутри команды.

### Фаза 3 — Оценка проекта

Материалы по дальнейшей детализации и оценке выбранного проекта.

В рамках последующей проработки проекта также рассматриваются сценарии использования системы, включая Use Case Diagram и Activity Diagram.

### Фаза 4 — Прогнозирование

Материалы, связанные с прогнозированием параметров проекта и работой с неопределённостью.

### Фаза 5 — Планирование

Материалы по планированию сроков, последовательности и организации дальнейших работ.

## Выбранная концепция

### A2 — Система автоматизации внутренних заявок и сервисных запросов

Внутренний сервис для автоматизации работы с обращениями сотрудников.

Система предполагает:

- создание и категоризацию заявок;
- маршрутизацию заявок;
- назначение исполнителей;
- работу со статусами;
- контроль сроков и SLA;
- согласования;
- комментарии и вложения;
- базу знаний;
- формирование отчётности.

Дальнейшие этапы работы в репозитории посвящены последовательной проработке этой концепции.
