# Фаза 2. Декомпозиция работ Фазы 3

**Проект:** A2 - Система автоматизации внутренних заявок и сервисных запросов (Service Desk)

Работа Фазы 3 разбита на отдельные задачи с понятным результатом.  
Задачи сформулированы как работы по **оценке проекта**, а не как разработка продукта.

## Список задач

| №   | Задача | Ожидаемый результат | Блок Фазы 3 |
|-----|--------|---------------------|-------------|
| T1  | Сформулировать список ролей (актёров) системы | Перечень ролей: Заявитель, Исполнитель, Руководитель, Администратор и др. | Сценарии |
| T2  | Набросать диаграмму вариантов использования (Use Case Diagram) | Диаграмма с ролями и связями use cases | Сценарии |
| T3  | Описать основные сценарии использования (не менее 10) | Карточки сценариев: цель, предусловия, основной ход, результат | Сценарии |
| T4  | Описать альтернативные и негативные ветки сценариев | Дополнения к карточкам: альтернативы, ошибки, исключения | Сценарии |
| T5  | Проверить полноту и согласованность сценариев | Проверенный и согласованный набор из ≥ 10 сценариев | Сценарии |
| T6  | Изучить метод COSMIC Function Points | Краткое описание метода и правил COSMIC | COSMIC |
| T7  | Выделить функциональные процессы по сценариям | Список функциональных процессов системы | COSMIC |
| T8  | Определить операции с данными (Entry, Exit, Read, Write) по каждому процессу | Таблица операций COSMIC по процессам | COSMIC |
| T9  | Рассчитать размер проекта в COSMIC Function Points | Итоговая таблица + число CFP | COSMIC |
| T10 | Изучить метод Use Case Points (UCP) | Краткое описание метода по классификации и факторам | UCP |
| T11 | Классифицировать сценарии (Simple / Average / Complex) | Таблица классификации use cases с обоснованием | UCP |
| T12 | Оценить технические факторы (TFactor) и факторы окружения (EFactor) | Заполненные таблицы факторов с пояснениями | UCP |
| T13 | Рассчитать UCP и перевести в человеко-часы | Итоговое значение UCP + оценка трудозатрат (с коэффициентом) | UCP |
| T14 | Организовать и провести коллективную экспертную оценку трудозатрат | Протокол сессии (Planning Poker / Delphi / обсуждение) | Экспертная оценка |
| T15 | Агрегировать экспертные оценки по сценариям / блокам | Сводная таблица оценок + итоговая трудоёмкость проекта | Экспертная оценка |
| T16 | Сравнить результаты COSMIC, UCP и экспертной оценки | Таблица сравнения + анализ расхождений | Выводы |
| T17 | Сформулировать выводы о масштабе, команде, сроках и приоритетах | Определить размер, состав команды, ориентировочный срок, что можно отложить, а что нельзя | Выводы |
| T18 | Оформить итоговые материалы Фазы 3 (таблицы, диаграммы, текст) | Заполнить репозиторий материалами Фазы 3 | Оформление |

## Группировка по блокам

- **Use Cases диаграмма проекта ** — T1–T5 (5 подзадач) 
- **Оценить проект в COSMIC Function Points** — T6–T9 (4 подзадачи) 
- **Оценить проект в Use Case Points ** — T10–T13  (4 подзадачи)
- **Экспертная оценка** — T14–T15  (2 подзадачи)
- **Выводы и оформление** — T16–T18

## Примечание

Всего **18 задач**. Такое разбиение достаточно детально для оценки сложности и распределения между участниками, но не избыточно.
