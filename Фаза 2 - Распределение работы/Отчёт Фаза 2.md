### 1.1. Оценка трудозатрат

Участники оценивали, сколько человеко-часов потребуется одному человеку для выполнения каждой учебной задачи. Использовалась шкала 1, 2, 3, 4, 5, 6 и 8 часов. Оценки задавались в человеко-часах.

Для каждой задачи сохранены три индивидуальных значения. Плановая трудоёмкость задачи рассчитана как их среднее арифметическое:

$$
t_i = \frac{t_{i,\text{Алина}} + t_{i,\text{Ольга}} + t_{i,\text{Никита}}}{3}.
$$

Например, для T3 участники указали 5, 6 и 3 часа. Среднее значение составляет (5 + 6 + 3) / 3 = 4 ч 40 мин. Суммарная плановая трудоёмкость 18 задач равна **50 ч 20 мин**.

Эта величина характеризует подготовку учебных материалов Фазы 3. Трудоёмкость разработки самого программного продукта A2 оценивается отдельно в Фазе 3.

## 2. Математическая постановка

Множество $I$ содержит 18 задач, множество $J$ — трёх участников. Для каждой пары определено предпочтение $p_{ij}$. Параметр $t_i$ обозначает среднее время задачи в часах. Двоичная переменная $x_{ij}$ равна единице при назначении задачи $i$ участнику $j$.

$$\max\; Z=\sum_{i\in I}\sum_{j\in J}p_{ij}x_{ij}$$

| Условие | Запись | Основание |
|---|---|---|
| Один ответственный | $\sum_j x_{ij}=1$ для каждого $i$ | У каждой карточки один владелец |
| Число задач | $\sum_i x_{ij}=6$ для каждого $j$ | 18 задач делятся поровну |
| Верхняя нагрузка | $\sum_i t_i x_{ij}\leq17{,}5$ ч для каждого $j$ | Средняя доля составляет 16 ч 46 мин 40 с. Округлённый предел оставляет 43 мин 20 с сверх неё |
| Область | $x_{ij}\in\{0,1\}$ | Допустимы все 54 пары |

При таком пределе участнику автоматически достаётся минимум 15 ч 20 мин, поскольку двое других вместе могут взять максимум 35 ч. Лимит — параметр учебной модели. Доступность и квалификация участников по отдельным задачам в исходных данных не измерялись. Общий объём часов постоянен при любом полном назначении.

## 5. Организационное решение

По результатам сравнения решили оставить согласованное ранее распределение. В нём у каждого участника по шесть задач и по 27 баллов предпочтений, а разница в плановой нагрузке составляет один час. Кроме того, T10 остаётся у Алины вместе с остальными её задачами по UCP, а Никита выполняет связанные задачи T16–T18: сравнение оценок, выводы и оформление итоговых материалов. Этот вариант уступает найденному оптимуму на два балла — 81 против 83, но сочли его более удобным для работы.
